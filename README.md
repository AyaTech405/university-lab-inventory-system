# 🧪 University Lab Inventory System

A web-based inventory management system designed to help universities manage laboratory equipment, track stock, and organize resources efficiently.

---

## 🚀 Project Overview

The **University Lab Inventory System** is a full-stack application that allows administrators and lab managers to:

- Track laboratory equipment and materials
- Manage inventory (add, update, delete items)
- Monitor stock availability
- Organize lab resources in a structured way

This system aims to reduce manual tracking errors and improve resource management in academic laboratories.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript (or React if used)
- **Backend:** Node.js / Express.js
- **Database:** MongoDB / MySQL (specify your DB)
- **Version Control:** Git & GitHub

---

## 📌 Features

- 🔍 View all lab equipment in a structured table
- ➕ Add new items to inventory
- ✏️ Update existing equipment details
- ❌ Delete items from the system
- 📊 Track quantity and availability
- 🧾 Simple and intuitive user interface
